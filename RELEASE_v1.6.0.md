# v1.6.0 — автоматический расчёт стоимости аренды

В релизе появился настраиваемый расчёт стоимости аренды по выбранному времени.

## Что нового

- 💰 новый раздел `/admin → Тарифы`;
- тариф настраивается отдельно для каждой формы;
- базовая стоимость;
- количество часов, включённых в базу;
- цена каждого начатого дополнительного часа;
- расчёт интервалов через полночь, например `21:00 → 05:00`;
- предварительная цена показывается клиенту перед отправкой заявки;
- рассчитанная сумма автоматически записывается в поле «Стоимость» заявки;
- администратор по-прежнему может изменить итоговую цену вручную;
- исходный автоматический расчёт сохраняется отдельно и отображается в карточке заявки.

## Пример

Тариф:

```text
60 000 ₽ — первые 6 часов
10 000 ₽ — каждый начатый дополнительный час
```

Аренда:

```text
21:00 → 05:00 = 8 часов
```

Расчёт:

```text
60 000 + 2 × 10 000 = 80 000 ₽
```

Если аренда длится 6 ч 20 мин, дополнительные 20 минут считаются как один начатый дополнительный час.

## После обновления

Тарифы выключены по умолчанию. Откройте:

```text
/admin → 💰 Тарифы → Аренда Фабрики
```

и последовательно задайте базовую стоимость, включённые часы и цену дополнительного часа. После этого включите расчёт.

## Docker

```bash
sudo docker pull ghcr.io/spacesarmat/tgautoreply:latest
```

После загрузки нового образа пересоздайте контейнер. SQLite-база и старые заявки сохраняются.
