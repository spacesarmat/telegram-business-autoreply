# Возможности Telegram Business AutoReply

Telegram Business AutoReply — self-hosted автоответчик и мини-CRM для личного Telegram Premium / Business-аккаунта.

Бот работает через официальный Telegram Bot API и Business Connection: клиент пишет **в ваш обычный личный Telegram-чат**, а бот помогает отвечать, запускать формы, принимать заявки и управлять бронированиями от имени вашего Business-аккаунта.

## 🚀 v2.0 — расширенное управление площадкой

В v2.0 добавлен слой бизнес-правил поверх существующих форм, тарифов и CRM:

- регулярные блокировки календаря по дням недели;
- динамические надбавки по количеству гостей, дню недели и ночному времени;
- тип вопроса **📎 Файл / фото** с просмотром вложений в Web Admin;
- CRM-раздел **Клиенты** с историей и заметками менеджера;
- Web Admin роли **owner / manager / viewer**;
- аудит административных действий;
- аналитика и экспорт **CSV / Excel**;

Фактическая интеграция с платёжным провайдером не зашита в код: администратор задаёт собственный URL-шаблон. Для Google Calendar используется стандартная подписка на приватный ICS URL; для внешнего Google Calendar Web Admin должен быть доступен по HTTPS из интернета.

### 📅 Выбор даты

Для поля «Дата» отображается inline-календарь.

Возможности календаря:

- выбор дня кнопкой;
- переключение месяцев;
- кнопка «Сегодня»;
- ручной ввод даты в формате `ДД.ММ.ГГГГ`;
- отображение занятых и частично занятых дат.

Обозначения:

- `×` — дата полностью занята;
- `•` — часть времени уже занята.

### 🕐 Выбор времени

Пользователь может выбрать время начала и окончания кнопками.

Поддерживается ручной ввод времени.

Для аренды можно указать полноценный интервал:

```text
21:00 → 05:00
```

Если время окончания меньше времени начала, бот автоматически понимает, что окончание приходится на следующий день.

Пример:

```text
Дата: 21.10.2026
Начало: 21:00
Окончание: 05:00

Продолжительность: 8 часов
```

### 🌙 Аренда через полночь

Интервал `21:00–05:00` резервирует:

```text
21.10.2026  21:00–24:00
22.10.2026  00:00–05:00
```

Это предотвращает двойное бронирование как вечером первого дня, так и ночью следующего.

### 🎛 Выбор из вариантов

Для любого вопроса можно включить тип **🎛 Выбор из вариантов** и задать до 20 собственных кнопок. Варианты редактируются из Telegram `/admin` и Web Admin.

Для стандартной формы **«Аренда Фабрики»** вопрос «Формат» содержит:

- 🎧 Рейв / клубная вечеринка
- 🎂 День рождения
- 🥂 Корпоратив
- 💍 Свадьба / банкет
- 🎤 Концерт / выступление
- 📸 Съёмка / контент
- 🎓 Выпускной
- 🔒 Закрытое мероприятие
- ✨ Другое

При выборе **«Другое»** бот просит клиента описать свой формат текстом. Сохранённый ответ выглядит, например, как `Другое: презентация бренда`.

### 👥 Количество гостей

Для вопросов типа **👥 Количество гостей** бот показывает готовые варианты:

- до 50;
- от 50 до 100;
- от 100 до 150;
- от 150 до 250;
- от 250 до 400;
- более 400.

Пользователь может выбрать диапазон кнопкой или ввести число вручную. Например, `120` будет сохранено как **«от 100 до 150»**. Стандартные вопросы с названием «Количество гостей» автоматически переводятся на этот тип при обновлении.

### 📱 Контакт клиента

Основной способ — ручной ввод номера.

Пример:

```text
+7 999 123-45-67
```

Бот:

- проверяет номер;
- принимает 7–15 цифр;
- допускает `+`, пробелы, скобки и дефисы;
- нормализует номер перед сохранением;
- не принимает значения вроде `4`, `123` или произвольный текст.

Если клиент Telegram отправляет объект Contact, бот также умеет его принять.

## 🧹 Чистое заполнение формы

При наличии права Telegram Business **«Удаление входящих»** бот может удалять технические ответы пользователя после их сохранения в форму.

В результате в чате остаётся аккуратное сообщение формы, а не длинная цепочка ответов.

Форма ведётся в одном редактируемом Business-сообщении, поэтому старые inline-кнопки не остаются активными.

## 🕒 Локальный часовой пояс

Бот хранит технические timestamps в UTC, но **все пользовательские даты и время отображает в часовом поясе бизнеса**, заданном переменной `TZ`.

Пример:

```env
TZ=Europe/Moscow
```

Локальная зона применяется к:

- времени создания заявки;
- журналу изменений;
- дате «сегодня» в календаре;
- спискам занятости;
- датам в списке заявок.

Telegram Bot API не передаёт часовой пояс каждого клиента, поэтому используется единая зона бизнеса/аккаунта.

## 💰 Автоматический расчёт аренды

В `/admin → 💰 Тарифы` можно настроить расчёт отдельно для каждой формы, где есть дата, время начала и окончания.

Параметры тарифа:

- базовая стоимость;
- количество часов, включённых в базовую стоимость;
- стоимость каждого начатого дополнительного часа;
- включение/выключение автоматического расчёта.

Пример тарифа:

```text
Базовая стоимость: 60 000 ₽
Включено: 6 часов
Дополнительный час: 10 000 ₽
```

Для интервала:

```text
21:00 → 05:00
```

продолжительность равна 8 часам, поэтому расчёт будет:

```text
60 000 ₽ + 2 × 10 000 ₽ = 80 000 ₽
```

Если дополнительное время составляет неполный час, оно считается как начатый час. Например, 6 ч 20 мин при базе 6 ч — это один дополнительный час.

Перед отправкой заявки клиент видит **предварительную стоимость**. После отправки рассчитанная сумма автоматически становится стоимостью заявки в мини-CRM. Администратор может изменить итоговую сумму вручную; исходный автоматический расчёт сохраняется отдельно и остаётся виден в карточке заявки.

Тарифы выключены по умолчанию, чтобы после обновления существующего бота клиентам случайно не показывалась не настроенная цена.

## 🧰 Дополнительные услуги и технические буферы

Начиная с v1.7.0 к каждой форме можно привязать собственный список платных или бесплатных дополнительных услуг. Клиент отмечает нужные позиции перед финальным подтверждением заявки, а выбранные услуги сохраняются вместе с заявкой.

Если для формы включён автоматический тариф, итог считается как:

```text
аренда + выбранные дополнительные услуги = предварительный итог
```

Пример:

```text
Аренда: 80 000 ₽
Звук: 15 000 ₽
Свет: 10 000 ₽
Итого: 105 000 ₽
```

Для каждой формы настраиваются технические буферы **до** и **после** аренды. Они не влияют на оплачиваемую длительность, но расширяют занятость календаря. Например, аренда `21:00–05:00` с буфером 2 часа до и 2 часа после занимает календарь с `19:00` до `07:00` следующего дня.
## 🔔 Уведомление об изменении стоимости

Если администратор вручную меняет поле **💵 Стоимость** в карточке заявки, бот уведомляет заказчика в исходном Telegram Business-чате. Сообщение содержит предыдущую стоимость, новую стоимость, текущую предоплату и остаток.

Если установить ту же сумму повторно, дубликат не отправляется. Если Telegram временно не позволяет отправить Business-сообщение, изменение стоимости не откатывается: администратор получает предупреждение о том, что клиент не был уведомлён.

Доступ защищён `WEB_ADMIN_USERNAME` и `WEB_ADMIN_PASSWORD`. Сессия хранится в HttpOnly cookie, POST-запросы защищены CSRF-токеном. `/health` остаётся без авторизации для Docker healthcheck. Для доступа из интернета рекомендуется HTTPS через reverse proxy.

## ⚙️ Конкурентная обработка

Бот рассчитан на одновременную работу нескольких клиентов. Разные Telegram-чаты обрабатываются параллельно, но для каждого `chat_id` действует отдельная очередь. Поэтому два быстрых сообщения одного пользователя не могут одновременно изменить один и тот же шаг формы.

Дополнительная защита включает:

- per-chat `asyncio.Lock`;
- отбрасывание повторного callback, пока такое же нажатие уже выполняется;
- глобальный semaphore для ограничения нагрузки;
- `submission_token` с UNIQUE-индексом SQLite;
- идемпотентный submit: повторная попытка возвращает существующую заявку;
- мониторинг активных и ожидающих updates.

Лимит параллельной обработки задаётся переменной:

```env
MAX_CONCURRENT_UPDATES=32
```

Для обычной установки менять значение не требуется.
