# Возможности Telegram Business AutoReply

Telegram Business AutoReply — self-hosted автоответчик и мини-CRM для личного Telegram Premium / Business-аккаунта.

Бот работает через официальный Telegram Bot API и Business Connection: клиент пишет **в ваш обычный личный Telegram-чат**, а бот помогает отвечать, запускать формы, принимать заявки и управлять бронированиями от имени вашего Business-аккаунта.

## Основные возможности

### 🤖 Автоответчик Telegram Business

- Автоматический ответ при первом обращении клиента.
- Повторный автоответ после настраиваемого периода бездействия.
- Стандартный интервал — 168 часов / 7 дней.
- Бот отвечает в исходном личном чате, а не переводит клиента в отдельный чат с ботом.
- Поддержка официального Telegram Business Connection.
- Работа без Telethon, `api_id`, `api_hash` и user-session.

### ⚡ Ручной вызов меню

Клиент может вызвать главное меню в любой момент, написав, например:

```text
/menu
меню
заявка
```

Список фраз настраивается через `/admin`.

Ручной вызов меню не зависит от интервала автоответа.

### 🧩 Конструктор кнопок

Через `/admin` можно:

- создавать новые кнопки;
- менять название;
- менять порядок;
- включать и выключать кнопки;
- удалять кнопки;
- назначать обычный текстовый ответ;
- привязывать кнопку к пошаговой форме;
- настраивать количество кнопок в строке.

Стартовые кнопки:

1. Написать пользователю
2. Заказать мероприятие
3. Аренда оборудования
4. Аренда Фабрики
5. Другое

## 📝 Пошаговые формы

Каждая кнопка может запускать отдельную форму.

Поддерживается:

- произвольное количество вопросов;
- обязательные и необязательные поля;
- изменение порядка вопросов;
- кнопка «Назад»;
- кнопка «Пропустить»;
- кнопка «Главное меню»;
- отмена заявки;
- предварительный просмотр перед отправкой;
- сохранение незавершённой формы в SQLite;
- восстановление после перезапуска контейнера.

### Типы вопросов

Поддерживаются:

- `⌨️ Текст`
- `📅 Дата`
- `🕐 Время`
- `📱 Контакт`

Тип вопроса меняется через `/admin → Формы`.

### 📅 Выбор даты

Для поля «Дата» отображается inline-календарь.

Возможности календаря:

- выбор дня кнопкой;
- переключение месяцев;
- кнопка «Сегодня»;
- ручной ввод даты в формате `ДД.ММ.ГГГГ`;
- отображение занятых и частично занятых дат.

Обозначения:

- `×` — дата полностью занята;
- `•` — часть времени уже занята.

### 🕐 Выбор времени

Пользователь может выбрать время начала и окончания кнопками.

Поддерживается ручной ввод времени.

Для аренды можно указать полноценный интервал:

```text
21:00 → 05:00
```

Если время окончания меньше времени начала, бот автоматически понимает, что окончание приходится на следующий день.

Пример:

```text
Дата: 21.10.2026
Начало: 21:00
Окончание: 05:00

Продолжительность: 8 часов
```

### 🌙 Аренда через полночь

Интервал `21:00–05:00` резервирует:

```text
21.10.2026  21:00–24:00
22.10.2026  00:00–05:00
```

Это предотвращает двойное бронирование как вечером первого дня, так и ночью следующего.

### 📱 Контакт клиента

Основной способ — ручной ввод номера.

Пример:

```text
+7 999 123-45-67
```

Бот:

- проверяет номер;
- принимает 7–15 цифр;
- допускает `+`, пробелы, скобки и дефисы;
- нормализует номер перед сохранением;
- не принимает значения вроде `4`, `123` или произвольный текст.

Если клиент Telegram отправляет объект Contact, бот также умеет его принять.

## 🧹 Чистое заполнение формы

При наличии права Telegram Business **«Удаление входящих»** бот может удалять технические ответы пользователя после их сохранения в форму.

В результате в чате остаётся аккуратное сообщение формы, а не длинная цепочка ответов.

Форма ведётся в одном редактируемом Business-сообщении, поэтому старые inline-кнопки не остаются активными.

## ✅ Итоговая заявка в том же чате

После подтверждения полная карточка заявки остаётся в исходном личном чате с клиентом.

Пример:

```text
✅ Заявка №18 принята

Аренда Фабрики

Дата: 21.10.2026
Начало: 21:00
Окончание: 05:00
Количество гостей: 300
Формат: Рейв
Телефон: +79991234567
Комментарий: —

Спасибо! Заявка сохранена.
```

Заявка также сохраняется в SQLite.

## 📋 Мини-CRM заявок

В `/admin → Заявки` доступен список заявок.

Статусы:

- 🆕 Новая
- 🟡 В работе
- ✅ Подтверждена
- 💰 Оплачена
- 🏁 Завершена
- ❌ Отказ

При реальном изменении статуса клиент получает уведомление в том же Telegram Business-чате.

Повторная установка уже активного статуса не отправляет дубликат.

## 📅 Управление занятостью

В `/admin → Занятость` можно вручную блокировать даты и интервалы.

Примеры:

Весь день:

```text
21.10.2026
```

Часть дня:

```text
21.10.2026
18:00-23:00
```

Ночной интервал:

```text
21.10.2026
21:00-05:00
```

Можно добавить комментарий:

```text
18:00-23:00 | монтаж
```

### Автоматическая блокировка

При переводе заявки в статус:

- `Подтверждена`
- `Оплачена`
- `Завершена`

время заявки автоматически резервируется.

При конфликте с существующим бронированием бот не позволит подтвердить пересекающуюся заявку.

## 🛠 Админ-панель

Управление выполняется прямо в Telegram командой:

```text
/admin
```

Доступно:

- включение/выключение автоответчика;
- редактирование приветствия;
- изменение cooldown;
- настройка сетки кнопок;
- конструктор кнопок;
- конструктор форм;
- настройка вопросов;
- выбор типа вопроса;
- привязка форм к кнопкам;
- настройка фраз вызова меню;
- список заявок;
- изменение статусов;
- управление занятостью;
- статистика;
- просмотр Business Connection;
- проверка права удаления входящих сообщений.

## 💾 SQLite

Все рабочие данные сохраняются локально:

- настройки;
- кнопки;
- формы;
- вопросы;
- контакты;
- активные формы;
- заявки;
- статусы;
- занятость;
- статистика;
- Business Connection.

Перезапуск и пересоздание Docker-контейнера не удаляют данные.

Для ZimaOS база хранится в:

```text
/DATA/AppData/telegram-business-autoreply/data/bot.db
```

## 🐳 Docker / ZimaOS / CasaOS

Проект поставляется как Docker-контейнер.

Готовый multi-arch образ:

```text
ghcr.io/spacesarmat/tgautoreply:latest
```

Архитектуры:

- `linux/amd64`
- `linux/arm64`

Поддерживаются:

- Docker Compose;
- ZimaOS;
- CasaOS;
- обычный Linux Docker host.

Образ автоматически собирается GitHub Actions после push в `main`.

## ❤️ Healthcheck

В контейнер встроена status/health страница.

По умолчанию:

```text
http://IP_ZIMAOS:18080
```

Docker healthcheck контролирует состояние приложения.

## 🔐 Безопасность

- Токен бота передаётся через переменную `BOT_TOKEN`.
- Доступ к `/admin` ограничен `ADMIN_IDS`.
- Можно указать несколько администраторов.
- Данные хранятся локально в SQLite.
- Боту можно выдавать только необходимые Telegram Business-права.
- Не требуется хранить Telegram user-session.

## Требуемые Telegram Business-права

Минимально:

- чтение сообщений;
- ответы на сообщения.

Для чистых форм дополнительно:

- удаление входящих сообщений.

## 💼 Расширенная карточка заявки

Начиная с v1.5.0 в админ-карточке заявки доступны:

- полная стоимость;
- предоплата / уже полученная сумма;
- автоматически рассчитанный остаток;
- внутренняя заметка, невидимая клиенту;
- история предыдущих заявок клиента;
- журнал последних изменений заявки;
- поиск по номеру, имени, username, телефону и содержимому формы.

Шаблоны уведомлений по каждому статусу редактируются в `/admin`. В сообщениях можно использовать сумму, предоплату и остаток.
