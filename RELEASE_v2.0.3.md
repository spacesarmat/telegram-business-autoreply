# v2.0.3 — описание базовой стоимости

Небольшой функциональный релиз для более понятного расчёта аренды.

## Что нового

- У каждого тарифа появилось многострочное поле **«Описание базовой стоимости»** до 1500 символов.
- Редактирование из Telegram `/admin` и Web Admin.
- Описание показывается клиенту в предварительном расчёте и итоговой карточке заявки.
- Значение попадает в `pricing_details` заявки как снимок условий на момент оформления.
- Исправлено отображение динамических надбавок в тексте расчёта.

Пример:

```text
💰 Предварительная стоимость: 80 000 ₽
Тариф: 60 000 ₽ за первые 6 ч + 10 000 ₽ за каждый начатый дополнительный час.

В базовую стоимость входит:
До 6 часов аренды
Мебель площадки
Базовая уборка
Дежурный администратор

Продолжительность: 8 ч.
```

## Обновление

SQLite мигрируется автоматически. Данные в `/data` удалять не нужно.

```bash
sudo docker pull ghcr.io/spacesarmat/tgautoreply:latest
```

После загрузки нового образа пересоздайте контейнер.
