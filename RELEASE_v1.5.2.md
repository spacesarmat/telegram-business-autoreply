# v1.5.2 — локальный часовой пояс вместо UTC

Исправлено отображение времени в Telegram: пользовательские и административные timestamps теперь переводятся в локальный часовой пояс бизнеса из `TZ`.

## Что изменилось

- 🕒 время создания заявки показывается локально;
- 🕘 журнал изменений заявки показывается локально;
- 📅 «Сегодня» в календаре определяется по локальной зоне;
- 📅 список занятости начинается с локальной даты;
- 📋 дата в списке заявок учитывает возможный переход даты относительно UTC;
- `/admin` показывает активный часовой пояс;
- при запуске проверяется корректность `TZ`;
- добавлен пакет `tzdata` для стабильной работы IANA timezone database в Docker.

## Настройка

В `.env` или Docker Compose задайте IANA timezone, например:

```env
TZ=Europe/Moscow
```

Другие примеры:

```env
TZ=Europe/Berlin
TZ=Asia/Dubai
TZ=America/New_York
```

Telegram Bot API не передаёт боту часовой пояс каждого собеседника, поэтому бот использует единый часовой пояс бизнеса/аккаунта.

## Важная техническая деталь

SQLite продолжает хранить служебные timestamps в UTC. Это намеренно: UTC безопаснее для сортировки, миграций и смены `TZ`. Конвертация выполняется только при отображении.
