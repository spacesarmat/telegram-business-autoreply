# v2.0.0 — расширенное управление бронированиями

Крупный релиз, который добавляет бизнес-правила, CRM-инструменты и интеграции поверх существующей системы Telegram Business AutoReply.

## Что нового

- Правила бронирования по форме: минимальная длительность, lead time, горизонт бронирования, закрытые дни и рабочее время.
- Повторяющаяся занятость по дням недели.
- Динамические надбавки по диапазону гостей, дню недели и ночному времени.
- Новый тип вопроса **Файл / фото**; вложения до 20 МБ сохраняются в `/data/uploads`.
- CRM-раздел **Клиенты** с историей и заметками.
- Web Admin роли `owner`, `manager`, `viewer`.
- Журнал аудита административных действий.
- Аналитика, CSV и Excel экспорт.
- Клиентский экран **Моя заявка** и запросы на изменение брони / услуг / отмену.
- Приватный iCalendar/ICS feed для подписки в Google Calendar и других календарях.
- Настраиваемая ссылка на предоплату с отправкой клиенту через Telegram Business.

## Совместимость

SQLite мигрирует автоматически. Старые заявки, формы, тарифы, занятость, reminders и backups v1.9.0 сохраняются. `WEB_ADMIN_USERNAME` / `WEB_ADMIN_PASSWORD` остаётся владельцем Web Admin.

## Новая необязательная переменная

```env
WEB_ADMIN_USERS=manager1:StrongPassword123:manager,viewer1:AnotherPassword123:viewer
```

Роли: `owner`, `manager`, `viewer`. Пароль каждого пользователя — не короче 10 символов.

## Важные замечания

- Google Calendar подключается подпиской на приватный ICS feed; для внешнего Google Calendar нужен публично доступный HTTPS URL.
- Встроенная оплата в этом релизе — генерация/отправка ссылки по вашему URL-шаблону. Автоматическое подтверждение платежа требует отдельной интеграции с конкретным платёжным провайдером.
- Приватный ICS feed выключен по умолчанию.

## Обновление ZimaOS

После публикации образа:

```bash
sudo docker pull ghcr.io/spacesarmat/tgautoreply:latest
```

Затем пересоздайте контейнер. Каталог `/data` не удаляйте.
