# v1.8.0 — Web Admin

Главное изменение релиза — полноценная веб-панель администрирования Telegram Business AutoReply.

## Что доступно в браузере

- 🏠 Dashboard и статистика
- 📋 Заявки: поиск, фильтры, карточка и история
- ✅ Смена статусов с уведомлением клиента
- 💵 Стоимость, предоплата и внутренняя заметка
- 💰 Тарифы, допуслуги, монтаж/уборка и технические буферы
- 📅 Ручная занятость календаря
- 📝 Формы и вопросы
- 🔘 Кнопки меню и привязка форм
- ⚙️ Основные настройки автоответчика

## Авторизация

Добавьте в окружение:

```env
WEB_ADMIN_USERNAME=admin
WEB_ADMIN_PASSWORD=your-strong-password-here
```

Пароль должен быть не короче 10 символов. При пустом пароле или значении `PASTE_...` Web Admin отключён.

После запуска:

```text
http://IP_ZIMAOS:18080/admin
```

`/health` остаётся доступным без авторизации для Docker healthcheck.

> Панель рассчитана прежде всего на локальную сеть. Если порт публикуется в интернет, используйте reverse proxy с HTTPS и ограничением доступа.

Telegram `/admin` продолжает работать параллельно.
